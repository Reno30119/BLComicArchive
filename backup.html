💾 資料備份

把書庫、標籤、待購清單的資料匯出成 JSON，或從備份還原

📦 匯出備份

按下按鈕會直接向 Firestore 重新讀取一次最新資料（不會用快取），把「書庫」「標籤」「待購清單」三個部分 全部打包成一個 JSON 檔案下載到你的電腦。建議在做大量修改或刪除前先匯出一份。

📥 匯入還原

選擇之前匯出的備份 JSON 檔案。這個還原只會補回備份裡有、但目前 Firestore 沒有的資料，不會刪除或覆蓋任何現有內容，適合用在「不小心刪錯東西，想把它補回來」的情境。

注意：還原是「補回遺漏的資料」，不會刪除任何現有內容；如果你需要「完全恢復成備份當下的樣子」（包含刪除備份之後才新增的東西），這個工具目前不支援這種完全替換的還原方式，需要另外處理。匯出的檔案請自行妥善保存（例如存到雲端硬碟），不要外流，裡面包含完整的書庫與待購清單資料。
